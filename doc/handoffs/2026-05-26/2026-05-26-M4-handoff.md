## 🏛 반드시 따라야 할 아키텍처 패턴 (위반 시 spec 정합성 깨짐)

### 1. PlayerStateMachine = StateMachine 파생 클래스 자체 보유 Playable map
spec §1.5 부록 B.18 **재해석** (IPlayable spec §4.5): Playable + FSM 둘 다 Actor 에 부착 OK, 단 갱신원이 갈리지 않게. M4 는 **StateMachine 안에 Playable 보유** (PlayablePlayerComponent 미부착) — heap=0, 영구.

```cpp
class PlayerStateMachine : public SJH::FSM::StateMachine<PlayerState, PlayerActor> {
  public:
    PlayerStateMachine(PlayerActor& owner) : StateMachine(owner, PlayerState::Idle) {
        RegisterState(std::make_unique<IdleState>(*this));   // self 참조 — Playable lookup 위해
        // ...
        playables_[PlayerState::Idle] = std::make_unique<SpriteSequencePlayable>(spriteRef, &idleClip);
        playables_[PlayerState::Idle]->SetIsLoop(true);   // PlayableBase 캐스트 또는 SpriteSequencePlayable 직접 핸들
        // ...
    }
    IPlayable* GetPlayable(PlayerState s) { auto it = playables_.find((uint64_t)s); return it != end ? it->second.get() : nullptr; }
  private:
    std::unordered_map<uint64_t, std::unique_ptr<SJH::Playable::IPlayable>> playables_;
};
```

### 2. State Entity = self-identifying (그래프 응집)
```cpp
class IdleState : public SJH::FSM::IFsmState<PlayerActor> {
    uint64_t GetStateFlag()   const override { return (uint64_t)PlayerState::Idle; }
    uint64_t GetTransitFlag() const override {
        return (uint64_t)(PlayerState::Move | PlayerState::Attack | PlayerState::Die);
    }
    void OnEnter (PlayerActor&) override { /* Playable Play */ }
    void OnUpdate(PlayerActor&, float dt) override { /* 입력 감지 → fsm.TryTransit */ }
    void OnExit  (PlayerActor&) override { /* Playable Stop */ }
};
```

### 3. `enum class PlayerState : uint64_t` — NONE=0 + 단일 비트
```cpp
enum class PlayerState : uint64_t {
    NONE   = 0,
    Idle   = 1ULL << 0,
    Move   = 1ULL << 1,
    Attack = 1ULL << 2,
    Die    = 1ULL << 3,
};
```

### 4. Bullet = Compound Actor 자유 함수 factory (Player 와 동일 패턴)
```cpp
struct BulletConfig {
    b2World* world;
    vmath::vec2 startPosition;
    vmath::vec2 direction;          // 정규화된 방향
    float speed = 20.0f;
    float damage = 10.0f;
    SJH::Scene::Actor* ownerEntity = nullptr;
};
std::unique_ptr<SJH::Scene::Actor> CreateBulletActor(const BulletConfig& cfg);
```

### 5. PhysicsLayer 마스크 — Bullet 의 충돌 대상 명시
- BulletPlayer category, mask = `Enemy | Wall` (자기 + Pickup + 다른 BulletPlayer 무시)
- BulletEnemy category, mask = `Player | Wall`

```

   ↓

T4 (Enemy + AI)                       ← Bullet 충돌 대상 필요
```

**병렬 가능**: T2 ↔ T4 (서로 무관). T1 은 T2 완료 후. T5 는 T3 후 즉시.
