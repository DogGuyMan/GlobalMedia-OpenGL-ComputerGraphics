2. **기존 Plan 1A를 대체 아닌 보강.** 제네릭 DataTable(json 홀더)+타입드 *Data+from_json+Load*Data 유지. BakingSheet는 추가 채택 개념만 제공.
3. **YAGNI/규모 적합.** 단일 게임 + 소량 마스터데이터다. MasterMemory식 코드젠+다중인덱스+쿼리, BakingSheet 다중소스 컨버터(Excel/Google), async/Task 는 과설계 가능성 높음 — 채택 시 *반드시* 정당화, 아니면 skip.
4. **C# 관용구 누수 금지**: KeyedCollection→`std::unordered_map`, Reference struct→C++ 등가(아래 설계), partial method/async→불필요.
