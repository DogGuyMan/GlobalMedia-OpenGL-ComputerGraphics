# 실용 환경 세팅 계획 v2 — AI 보조 C++ 렌더링 리팩토링 PoC

> **확정 입력**: 리팩토링 대상 = **C++ 호스트 렌더 코드만** · 탐지 = **아티팩트 + 픽셀 계층 검증** · 컴파일 타겟 = **단일(OpenGL/GLSL)** · 셰이딩 = **Slang(멀티타겟 컴파일러, PoC는 단일 타겟으로 핀)**

---

## v1 대비 핵심 변경 (지난 턴의 비약 교정)

1. **gate-0 신설** — 헤드리스 컨텍스트 + 결정성 카나리아 + 픽셀 노이즈 플로어 측정 + 입력 고정. 이게 선행되기 전엔 어떤 임계값도 잠금.
2. **검증을 2계층으로 분리** — Layer A(셰이더 아티팩트 byte-diff, 결정적·고속) → Layer B(픽셀 골든, 1차 행동 오라클). 노이즈 문제는 Layer B에만 남음.
3. **셰이더는 고정 입력** → 변이 테스트는 **C++ 호스트만** 대상(CITYWALK가 검증한 .cpp 경로). GLSL/Slang 변이 도구 리스크 소멸.
4. **Catch2 러너 결선 명시** — 골든 단언은 capture+diff를 호출하는 Catch2 테스트. 이것이 실행 단위.
5. **단일 타겟 → 골든 인프라 1배수.** 교차 타겟 발산 우려 제거.
6. **Clang 근거 정정** — CITYWALK식 AST 의존성 추출은 PoC에 불필요. Clang은 llvm-cov + clang-tidy/format으로만 정당화.
7. **골든 바인딩 명시** — 픽셀 골든은 캡처 머신 GPU/드라이버에, 아티팩트 골든은 Slang 버전·타겟·플래그에 종속.

---

## gate-0 — 결정성 바닥 측정 (모든 것의 선행 조건)

> 이게 통과하기 전엔 Phase 2 이후로 진행 금지. 지난 계획이 "같은 바이너리 → 같은 픽셀"을 측정 없이 가정한 비약을 여기서 차단한다.

- **입력 고정**: 단일 패스의 씬·카메라·에셋·프레임·시드 + Slang 컴파일 타겟/플래그를 PoC 상수로 핀.
- **헤드리스 컨텍스트**: 오프스크린 렌더 경로 확보(EGL headless / Xvfb + llvmpipe). → **결정점**: 실 GPU vs llvmpipe — 아래 측정으로 경험적 결정.
- **결정성 카나리아 (Layer A 선검증)**: 무변경 빌드를 N회 → Slang 컴파일 아티팩트가 byte-identical인지 확인. 아니면 셰이더 툴체인 자체가 비결정 → **먼저 수정**. (이 검증이 곧 아티팩트 diff를 신뢰할 수 있는 근거다 — 결정성을 가정하지 않고 측정한다.)
- **픽셀 노이즈 플로어 측정**: 동일 입력으로 같은 패스를 N회 렌더 → run-to-run 픽셀 분산 측정. 이 분산이 Layer B 임계값의 하한. **측정 전 "exact" 가정 금지.**
- **산출물**: 측정된 노이즈 플로어 수치 → Phase 2 Layer B 임계값의 확정 입력.

## Phase 1 — 결정적 빌드 / 툴체인

- **Clang/LLVM 버전 핀.** 근거: `llvm-cov`(커버리지) + `clang-tidy`/`clang-format`(품질 게이트). *(AST 의존성 추출은 PoC 비대상 — v1 과장 정정.)*
- CMake `-DCMAKE_EXPORT_COMPILE_COMMANDS=ON`(clang-tidy 입력), 백엔드 Ninja.
- **Slang 컴파일러 버전 핀 + 타겟 단일 고정**(예: Slang→GLSL, 또는 Slang→SPIR-V→GL_ARB_gl_spirv). 아티팩트 골든의 안정 전제.

---

## Phase 2 — 2계층 골든 회귀 (검증의 척추)

**Layer A — 셰이더 아티팩트 diff (고속·결정적·1차 게이트)**
- 리팩토링 전/후 컴파일된 셰이더 아티팩트(SPIR-V/GLSL)를 **byte-exact 비교**.
- 셰이더 소스는 고정이므로 기대값은 "변화 없음". diff 발생 = C++ 리팩토링이 셰이더 컴파일 입력(플래그·define·specialization constant)을 건드렸다는 신호.
- **사각지대 명시**: 런타임 유니폼 값·드로우 순서·상태 오류는 아티팩트에 안 나타남 → Layer A는 **보조 가드**일 뿐 1차 오라클이 아니다.

**Layer B — 런타임 픽셀 골든 (1차 행동 오라클)**
- 헤드리스로 패스 1장 렌더 → PNG + 메타데이터(해상도·포맷·GPU/드라이버·시드·커밋·Slang 버전/타겟).
- diff 허용오차 = **gate-0 노이즈 플로어에서 도출**(exact 또는 SSIM/perceptual — 측정값이 결정).
- 캡처 머신 GPU/드라이버에 바인딩 → **타 머신 비교 불가**(에이전트·CI는 동일 환경 강제).

**실행 순서**: A(빠른 실패) → B(심층). → 기존 `/refactor-pass`에 결선.

> ⚠️ **안전 규칙(유지)**: 골든은 사람 승인 베이스라인. 에이전트의 골든 덮어쓰기 금지. `/golden-update`는 사람 게이트 뒤에서만. (CITYWALK §5.4의 거짓 양성과 동형 위험.)

---

## Phase 3 — 헤드리스 렌더 경로 / Mock RHI (순서 정정)

- **우선순위: 실 RHI 헤드리스 경로 먼저.** 단일 패스를 엔진 전체 부팅 없이 오프스크린 구동 가능하면 Mock 불필요.
- Mock RHI는 패스를 **격리 구동할 수 없을 때만** 도입하는 fallback. → **결정점**: 실제 RHI 형태(내가 특정 불가).
- 수용 기준: Mock 경유 출력 ≈ 실 경로 출력(허용오차 내). 불일치 시 Mock 신뢰 불가.

---

## Phase 4 — 변이 테스트 (C++ 호스트 한정, 오라클 품질 검증)

- 대상 = **focal 렌더 패스의 C++ 호스트 코드**(셰이더 변이 아님). CITYWALK §5.1이 검증한 .cpp 경로.
- 연산자: 산술·비교·논리·상수.
- 지표: 변이 점수 = 골든(A∪B)이 잡아낸 변이 비율. 낮으면 골든이 느슨 → 거짓 양성 위험 신호.
- **비용 경고**: 변이 1개마다 재빌드+렌더+diff → 전체 클라이언트 규모에선 처리량 한계. **focal 패스 + 증분(diff 범위) 모드**로 스코프 제한. → **결정점**: Mull(gitDiffRef 증분) vs universalmutator — 둘 다 C++ 대상.

---

## Phase 5 — Catch2 러너 + 에이전트 결선

- **Catch2 = 실행 단위**(v1 누락 보완): 골든 단언(A: 아티팩트 동일, B: 픽셀 diff ≤ 임계값)을 Catch2 `TEST_CASE`가 capture+diff 호출 후 assert.
- **llvm-cov 역할 부여**: 골든 렌더 시 focal C++ 호스트 코드의 라인/분기 커버리지 측정 → 골든이 대상 경로를 **실제로 밟는지** 확인(공허한 통과 방지).
- `hooks.json` 격리 검증 + 슬래시 커맨드 ↔ Phase 2~4 결선(v1 유지).
- MCP: PoC엔 로컬 스크립트로 충분. 범위 확정 후 결정.

---

## Phase 6 — CI (미구축) / Phase 7 — 컨벤션·Quality Gate (미구축)

- **CI**: 골든(A→B) + 커버리지 + 변이를 머지 게이트로. 캡처 머신과 **동일 GPU/드라이버 강제**. → 결정점: CI 플랫폼.
- **컨벤션**: clang-format + clang-tidy 설정 = Quality Gate 강제 대상. → 결정점: 팀이 규칙 확정.

---

## 최소 First-Green 경로 (정정판)

1. **gate-0 통과** — 아티팩트 byte-동일 카나리아 + 픽셀 노이즈 플로어 측정 + 입력 고정
2. 빌드 성공(Phase 1)
3. 첫 골든 캡처(A 아티팩트 + B 픽셀) + **사람 승인**
4. 무변경 리팩토링 → A 동일 & B 노이즈 내 일치(파이프라인 정상 입증)
5. C++ 호스트에 의도적 변이 1개 → A 또는 B가 **반드시** 잡음(오라클 유효 입증)

> 4·5 통과 후에야 에이전트 자동화(Phase 5)로 확장.

## 남은 결정점 (이번 답변으로 대폭 축소됨)

- 실 GPU vs llvmpipe — **gate-0 노이즈 측정으로 경험 결정**
- 픽셀 허용오차 수치 — **gate-0 산출물로 확정**
- 단일 타겟 구체형(Slang→GLSL vs Slang→SPIR-V→GL)
- Slang 컴파일러 버전 핀
- 변이 도구(Mull 증분 vs universalmutator)
- CI 플랫폼 / 내부 컨벤션 규칙
