### 엔진 구체화
#### 외부 모듈
* sb7code
* box2d : 2d 충돌 
* Effekseer : 파티클 
* entt : 엔티티-컴포넌트-시스템(ECS) 사용
* tweeny : 트위닝 애니메이션 사용
* stb : image import
* assimp : 모델 로딩 모듈 
* spdlog : 로깅 유틸리티 모듈
#### 개인 모듈
* src/buffer : VBO, EBO, RBO, FBO 관리
* src/common : 클래스별 스마트 포인터 생성 매크로
* src/diagnostics : 디버깅용 OpenGL 진단 함수
* src/input : 키바인딩 인풋 모듈
* src/layout : VAO 책임 모듈
* src/material : Shader과 Program에 의존을 맺는 머티리얼 모듈
* src/object : Mesh, Model, 카메라 등등 책임 
* src/program : Shader를 입력받아 GLProgram 생성 모듈
* src/resource_registry : Image, Texture, Material, Model 전역 자원 관리
* src/shader : 쉐이더 컴파일 모듈
